## 3. Security Report

- **Header Security**: Helmet protection (`x-dns-prefetch-control`, `x-frame-options`, `x-powered-by` disabled).
- **Data Protection**: Soft deletion (`isDeleted: false`, `deletedAt`) active across all Mongoose schemas; zero physical deletes on main collections.
- **Environment Isolation**: No hardcoded API keys or database secrets in client code. Configurable via `.env` and `constants.dart`.

---

## 4. Performance Report

- **Image Compression**: Cloudinary pipeline automatically transforms cover and gallery uploads into responsive WebP/AVIF formats.
- **Database Querying**: Compound indexes on `isDeleted + status + createdAt` and `isDeleted + status + categoryId/locationId` guarantee $O(\log N)$ query times up to 100,000+ temples.
- **Client Cache**: Local Hive storage eliminates redundant network calls for offline saved shrines.
